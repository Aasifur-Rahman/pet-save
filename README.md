# Pet Save 

This Is a React + Vite project. This project has many features which are used in real time scenarios

 Project Techs:
- Use of React js with Accessible Components
- React Router for Routing
- Framer Motion for Animation & Tailwind, DaisyUI for Component Library
- For Changing Themes used ThemeProvider using Local storage implementation & Daisy UI
- For Authentication Firebase is used here
- Used Tanstack Query for state-management
- For fetching data Axios
- Use of React Hook form for controlling the forms
- Use of React Icons
- SweetAlert for Alerts

- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh
